Everything TrueMap can do, and how.

TrueMap is a small USB board that sits between your keyboard, mouse or foot pedal and the computer. It changes what each button does before the computer ever sees it, so your setup works in every program, on any workstation, with nothing installed.

Set up in 5 minutes Scroll lock and auto-scroll Copy, paste, undo macros Profiles per device Something's off

01What TrueMap does

One box, any input, any output.

Keyboard · mouse · pedal · knob→ TrueMap board→ Workstation (sees a keyboard, mouse, PowerMic or pedal)

Every press, click, scroll and turn goes through the board. For each one it checks your mappings: if one matches, it sends what you chose instead; if none match, the input passes through unchanged. All of it runs on the board itself, so:

  • Nothing to install on the workstation. Locked-down hospital PCs are fine.
  • It works in every program, including PowerScribe when it isn't the active window (the board can pretend to be a PowerMic or a foot pedal).
  • Your setup travels with you. Unplug the board, take it to another reading room, and it behaves the same.

02First setup

From box to working mapping.

  1. Plug your devices into the board, and the board into the computer. A USB hub on the board's input lets you use several devices; each hub socket is a port (1, 2, 3…).
  2. Open the configurator in Chrome or Edge (they can talk to USB serial devices). Click Open device and pick the board in the list. Its settings load straight away (switch that off per board in Settings → Board settings).
  3. Tell it what's plugged in. On Mappings → Your devices, pick a picture for each port (68-key keyboard, G502, EM06, foot pedal…). It only changes the picture; it makes clicking keys easy.
  4. Click a key in the picture, then pick what it should send from the output list. That's a mapping.
  5. Click Save to device. The board uses the new setup straight away.
  6. Check it in Live test: press the key and watch what the computer receives.

Not sure what a button sends? Open Live test and press it. The raw code table shows its name, code and port.

03What your computer sees

Settings → Board settings → What your computer sees.

The board always shows up as a keyboard and mouse (so unmapped keys keep working). On top of that it can pretend to be one more device. Change it and click Save to board; the board restarts as the new device and you click Open device again.

TypeThe computer seesUse it for
Mouse and keyboardA normal keyboard and mouseGeneral remapping, macros, scroll lock
Foot PedalA 3-pedal dictation foot pedalPowerScribe pedal actions from any key
PowerMic IIA Nuance PowerMic II (plus a silent microphone)Dictate, Next/Previous Field and the other mic buttons from any key
PowerMic 4A PowerMic 4The newer mic's buttons, including Function A–D
SpeechMike PremiumA Philips SpeechMike (SMP3700)Software that expects a SpeechMike
Absolute mouse and keyboardA touchscreen-style mouseJumping the pointer to fixed screen spots
Gamepads (Switch, PS4 stick, Stadia, XAC)A game controllerAccessibility setups

In PowerMic mode the board also appears as a microphone in Windows Sound settings, like a real PowerMic II. It only sends silence, so keep PowerScribe's audio on your real microphone. Unplug any real PowerMic or pedal while using the board: PowerScribe may only listen to the first one it finds.

Board name

Under Name, restart and automatic profiles you can name the board (up to 24 characters). The name shows on the settings port, and as the device name when the type is Mouse and keyboard. Emulated devices (PowerMic, pedal) keep their real names so PowerScribe recognises them. It's saved on the board, not per profile, and applies after a restart.

04Mappings

An input, an output, and when it applies.

A mapping says “when this is pressed, send that”. You can make them by clicking the device picture or with Add mapping in the table under it.

Making one from the picture

  1. Click a key or button in the picture. Its panel opens on the right.
  2. Pick the output: a key, shortcut, mouse button, dictation button, macro or a TrueMap action. Type to search the list.
  3. Optional: pick a layer, tap/hold, or one of the per-key features (tap dance, cycle, hold time).
  4. Gold keys are mapped. Click one again to change or remove it.

The mapping table

ColumnWhat it means
InputThe button, key or axis that triggers it, and which port it must come from (or any port).
OutputWhat gets sent instead.
LayerWhich layers (0–7) the mapping is active on. Layer 0 is the normal one.
StickyA press turns the output on, the next press turns it off. Good for layer switches and holding a button down.
Tap / HoldOnly fires on a short tap, or only when held past the tap-hold threshold. One key can do two things.
ScalingMultiplies a movement (pointer, wheel). Negative reverses it; 0.5 halves it.

Ports

With a hub, the same key on two devices can do different things: map the input on port 2 and only the device on port 2 triggers it. Any port works whichever socket the device is in. Which picture goes with which port is saved with the profile.

Pass through

Pass through keys that aren't remapped (Settings) keeps everything you didn't map working normally. Turn it off for a device where only your mappings should do anything. Per-layer control is under All settings → Unmapped inputs passthrough on layer.

A mapped key stops sending its own key. If you map F2 to Dictate, F2 no longer types F2. Map another key to F2 if you still need it.

05Layers, tap and hold

More actions than you have buttons.

Layers are complete alternate sets of mappings, like the Fn key on a laptop. Layer 0 is always there; layers 1–7 are on only while you switch to them.

HowOutput to useBehaviour
Hold for a layerLayer 1–7 (non-sticky)The layer is on while the key is held.
Toggle a layerLayer 1–7 with Sticky tickedPress once to turn on, again to turn off.
SwitchSwitch to layer 1–7 / Switch to base layerStays on that layer until you switch back.
Next key onlyOne-shot layer 1–7The next key press uses that layer, then it's back to normal.

Tap and hold: tick Tap on one mapping and Hold on another for the same key. A quick press sends the tap action; holding past the Tap-hold threshold (All settings) sends the hold action. You can give a single key its own hold time in its panel (Hold time for this key), and choose to treat it as held as soon as another key is pressed.

Back to base: in Key features, Back to the base layer returns to layer 0 after a number of seconds without input, so a forgotten layer switch can't confuse the next person.

06Tap dance, cycles, combos

Made from a key's panel or the Mappings toolbar. Need TrueMap firmware 20 or later.

Tap dance

Tap, double tap, hold

Three actions on one key. Click the key, then Tap dance, and fill in each. The timing window is adjustable.

Cycle

Each press, the next action

Press 1 sends the first action, press 2 the second, and so on, then round again. Great for window layouts or EM06 keys.

Combo

Buttons together

+ Combo: buttons together, click two or more keys, Done, then pick the output.

For combos, Block each button's own action when they're pressed together decides whether the individual keys still fire. Blocking waits a few milliseconds to see if the other key follows; turn it off for keys where any delay matters.

Everything set up this way is listed under Settings → Key features → On this profile, where you can remove it.

07Wheels and knobs as keys

Turn a scroll wheel, tilt, jog dial or shuttle ring into separate key presses.

A wheel normally sends one movement value, so "up" and "down" can't be mapped separately on their own. Click the wheel (or a dial, tilt or ring) in the picture, choose Use as keys and its kind:

KindForWhat you get
RelativeScroll wheels, tilt, knobs that send clicksA "one way" key and an "other way" key, pressed once per notch.
Wraps 0–255Jog dials like the ShuttleXpress inner ringA key per step clockwise and anticlockwise.
Holds a positionSpring-loaded shuttle ringsNear and far keys each way, held while the ring is turned.

Then map those keys like any other. The wheel stops scrolling by itself on that port while it's used as keys. On the G502 picture the wheel tilts are already keys (F17/F18 once set up in Logitech's software, see Recipes).

In PowerScribe, check that the PowerMic or foot pedal is enabled as an input device. If PowerScribe ignores the board but Live test shows the button, the problem is on the PowerScribe side.

10Macros

Several keys, in order, from one press.

A macro is a list of steps; each step is the keys held at that moment. Build one in Macros → Macro builder:

  1. Pick a macro slot and give it a name (for example “Copy”). Names show in the output list.
  2. Add steps:
    • Type text: types a phrase (US layout; capitals add Shift for you).
    • Shortcut: press e.g. Ctrl+C once and it's added as a single step.
    • Record keys: type on this computer's keyboard, then Stop.
    • Enter, Any output… (mouse buttons, dictation buttons), and Pause (a wait in milliseconds).
  3. Optional: Repeat while held: after a delay, the macro repeats at a rate you choose until you let go.
  4. Click Use this macro and click the key it goes on. Then Save to device.

Moving macros to another profile

Under the builder, Copy this macro or Copy all macros, switch profile, then Paste. One macro goes into the macro you have selected; “all” go into the same macro numbers, so mappings that use them keep working. Names and repeat-while-held come along. The copy is kept in this browser until you copy something else. Click Save to device after pasting.

Macro or two mappings?

For a shortcut like Ctrl+C you can make two mappings (wheel click → Left Ctrl and wheel click → C). A macro is cleaner: one action per press, it shows up by name, and the keys go out in the right order. Use a macro.

If a macro does nothing: check it isn't empty, that it's actually mapped to the key (the key turns gold), that the mapping is on the right port and layer, and that no other mapping on the same key overrides it. Live test shows what goes out.

Macro step duration (All settings) sets how long each step is held. Raise it if a program misses keys.

11Expressions

Small programs for when nothing else fits. Macros → Expressions.

An expression is a short formula the board runs on every input report. It can read inputs, keep state and produce an output value, which you map like any other input. Most things people used expressions for (scroll lock, auto-scroll, direction keys) are now built in; use those first. They are simpler and faster.

Comments written /* like this */ aren't saved to the board but are kept in exported JSON files. The Examples tab has working expressions you can load and read.

12Examples

Ready-made setups under Macros → Examples.

Load one to see how something is built, then change it. Loading an example replaces what's on the page (not the board) until you save, so export your setup first if you want to keep it.

15Profiles

Up to 8 complete setups on one board.

A profile holds everything: mappings, macros, expressions, settings, key features, device pictures and device type. Save to device always saves into the profile in use.

  • Save as: on the Profiles tab, save the page into any slot with a name (e.g. “GE PACS reading”).
  • Switch with a button: map a key to Profile 1–8, Next profile or Previous profile.
  • Switch automatically: in Settings, under Switch profile when a device is plugged in, pick a device from the list of what's plugged in now (no typing IDs) or a port, and the profile to use. Up to 8 rules. Choosing “any device on port N” matches whatever is on that port.
  • Back up all profiles to one file, and Restore from a backup on another board or after a reset.
  • The side bar lists the profiles on the board, so you can see which one is in use.

17Firmware and safe start

Keeping the board up to date, and getting out of trouble.

Updating

  1. Download the latest firmware file (.uf2) for your board.
  2. Click Restart into firmware update mode (Settings), or hold the board's BOOT button while plugging it in.
  3. A drive called RPI-RP2 appears. Copy the .uf2 file onto it. The board restarts by itself.

Your profiles survive updates. The configurator works with boards on older firmware, and tells you when a feature needs a newer one.

Safe start

If a mapping ever locks you out (say, every key is remapped), hold Esc for 2 seconds within 8 seconds of plugging the board in. It starts with every mapping off until the next restart. Your saved settings aren't touched, so open the configurator and fix the setup.

18Recipes

Common reading-room setups.

Dictate from the mouse

Set the type to PowerMic II. Map a side mouse button to PowerMic Dictate, the other to Next Field. Leave PowerScribe in the background; it still reacts.

Scroll a stack by moving the mouse

Map a spare button to Scroll lock. Press it, move the mouse to scroll; any click or key ends it. Put Scroll lock faster/slower on two more buttons, or set the speeds in Key features.

Hands-free cine

Map ← to Auto-scroll up, press again for fast/slow and → to the down version. ← starts scrolling up fast, ← again goes slow, → turns round at the same speed. Any other key or a click stops it. Set the two speeds in Settings → Key features.

Copy, paste, undo on mouse buttons

Make three named macros (Copy = Ctrl+C, Paste = Ctrl+V, Undo = Ctrl+Z) with the Shortcut button, then put them on buttons.

Logitech G502 with all its buttons

The G502 handles some buttons inside the mouse (DPI, G-shift). To get them to the board, use Logitech's Onboard Memory Manager once and set them to keys nothing else uses, then map those in TrueMap:

G502 buttonSet in the Logitech tool to
Sniper (thumb)F13
DPI front / back (beside left button)F14 / F15
Behind the wheelF16
Wheel tilt right / leftF17 / F18

Save it to the mouse's onboard memory and close the Logitech app. The G502 picture in TrueMap is labelled with these keys.

One keypad, several jobs (EM06 / macro pad)

Use a Cycle on a key to step through hanging protocols or window layouts, one per press.

Different readers, one board

Save each person's setup as its own profile and put Profile 1, Profile 2… on a spare key, or let the board switch when it sees a particular keyboard or mouse.

19Troubleshooting

Quick checks, most likely first.

ProblemTry
The board isn't in the Open device listUse Chrome or Edge. Replug it. A board on very old firmware needs current TrueMap firmware first.
A mapping does nothingDid you Save to device? Is it on the right port and layer? Press the key in Live test and check the "Sent as" column.
A key stopped typingIt's mapped; mapped keys are taken over. Change or remove the mapping.
PowerScribe ignores the boardCheck the board type, unplug other dictation devices, and enable the PowerMic/pedal in PowerScribe.
A button double-clicks on its ownKey features → Pointer and scrolling → add a debounce (10–30 ms) for that port.
Stuck on a layer or in scroll lockPress any key (scroll lock), or set Back to the base layer. Live test shows the current state.
Locked out completelySafe start: hold Esc for 2 s just after plugging in.
"Needs the latest firmware"Update the board (section 17). The settings stay on the page and in saved files meanwhile.
