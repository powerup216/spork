To switch profiles with a key, pedal or button, map it to Profile 1–Profile 8, Next profile or Previous profile (in the output list). Map that key in every profile, or you can't switch back. A switch made with a key lasts until the board is unplugged; it always starts in the default profile. Switching to a profile with a different device type restarts the board.
